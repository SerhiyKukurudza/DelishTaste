# DelishTaste

An interactive web platform dedicated to sharing and discovering culinary recipes. This project allows cooking enthusiasts to find new ideas, share their own creations, and actively interact with the community.

## Features

The system is designed to be dynamic and supports different access levels:

### Access Profiles
The platform is divided into three types of accounts with distinct permissions:
* **Regular User:** Can browse the catalog, view recipes, publish their own creations, leave comments, and rate other users' recipes.
* **Administrator:** Has moderation permissions and can manage content (recipes, comments, and ratings) to maintain the quality of the platform.
* **Owner:** Maximum access level, with full control over the system, settings, and administrator management.

### Main Features
* **Recipe Exploration:** Interface to list and view detailed recipes.
* **Content Creation:** Dedicated forms for users to submit and save new recipes.
* **Feedback System:** Community interaction through text comments and a rating system.
* **API Integration:** The project features dedicated APIs to communicate with the database, ensuring the secure and efficient display and storage of recipes and user data.

## Technologies Used

The project was built using the following technologies:

* **Mustache:** A logic-less template engine used to dynamically generate and render HTML pages.
* **CSS:** Responsible for the application's overall design, layout, and responsiveness.
* **JavaScript:** Handles the application logic, client-side interactivity, and API endpoint consumption.
